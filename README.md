面向网约车从业资格考试的**单机离线**题库应用，Android 与 Windows 双端。

> **本仓库只存放编译好的安装包，不含源代码。**

## 下载

右侧 [Releases](../../releases) 或访问 <https://github.com/hesyer/wangyueche_exam-releases/releases> 下载最新版本。

| 平台 | 文件名格式 | 大小约 |
|---|---|---|
| Android | `wangyueche-exam-<版本号>.apk` | 24 MB |

## 功能

- **1500 道真题**，来源可追溯：全国公共科目 500 题、深圳城市题库 500 题、广州城市题库 500 题
- **完全离线**，题库与学习进度全部保存在本机，不联网、不上传、无账号
- **按官方规则组卷**：全国 50 题 + 城市 50 题，100 分钟，双科各 40 分合格
- **交卷即出分**，逐题对比你的答案与标准答案，自动收集错题
- 章节练习、题型筛选、书签、学习进度统计

## 快速上手

### Windows

1. 下载 `wangyueche-exam-<版本号>-windows.zip` 并解压
2. 双击 `wangyueche_exam.exe`，**无需安装**

> 首次打开 Windows 可能提示「未知发布者」——应用未做代码签名属正常情况，
> 点「更多信息 → 仍要运行」即可。

### Android

1. 下载 `.apk` 文件
2. 系统提示「禁止安装未知来源应用」时，按提示进入设置允许当前浏览器或文件管理器安装
3. 返回并点击安装

> 若之前装过测试版（debug 签名），需先卸载旧版再装正式版 —— 不同签名的包无法覆盖安装。

## 常见问题

**Q：换手机后学习进度会丢吗？**
A：进度按备考人保存在本机，不跨设备同步。换设备需重新建立。

**Q：题目有错漏怎么办？**
A：请在该版本 Release 下提交 Issue，我会核对原件后修正。

**Q：会收集我的个人信息吗？**
A：不会。应用不联网，授权信息（手机号掩码 + 短指纹）只存在本机。
